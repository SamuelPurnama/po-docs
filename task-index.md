# Overview of Tasks

<span class="audience">Part 2 · Task Documentation · For: Po users</span>

This part of the documentation tells you exactly what to tap to get things done in Po. Each task page lists what you need before you start, then numbered steps with screenshots.

If you haven't read Part 1, start with [Core Concepts](concept-core-concepts.md). The task pages assume you know what a *talk*, a *coaching card*, and a *score* are.

In the screenshots, a numbered mark such as **(2)** shows the part of the screen used in step 2.

## A Typical First Week with Po

Here is one way to get started. Each step links to the task that shows you how.

1. **On day 1,** install Po and set it up. See [Installing Po from TestFlight](task-install-po.md) and [Setting Up Po](task-set-up-po.md).
2. **Before your next talk,** such as a meeting, class, or call, ask the people you're talking with if you can record. Then tap the round microphone button to start recording, and slide it to stop when the talk ends. See [Recording a Talk](task-record-a-talk.md).
3. **A few minutes after the talk,** open it and read Po's feedback, starting with the **PRIORITY** card. See [Reviewing a Talk's Feedback](task-review-a-talk.md).
4. **After about 10 talks,** check your **Delivery** and **Content** scores to see which patterns keep coming up. See [Checking Your Scores Over Time](task-check-your-scores.md).
5. **Whenever you're ready,** practice with Po to prepare for an upcoming talk or to work on a habit you want to fix. See [Practicing for an Upcoming Talk](task-practice.md).
